# DeepSeek GenUI Logo

## 设计方向

蓝色鲸鱼与交互界面融合：鲸鱼呼应 DeepSeek，身体中的卡片负空间与滑块表达插件将聊天回答变成可操作工具的特点。采用纯色、简洁轮廓和透明背景，供浏览器扩展图标、README 和项目展示使用。

本轮为独立标志设计稿，尚未接入扩展清单。

## 生成方式

使用内置 image_gen 工具，透明背景。

## Prompt

```text
Use case: logo-brand.
Asset type: primary icon logo for "DeepSeek GenUI", an independent browser extension that turns DeepSeek chat answers into interactive tools, cards, visualizations and adjustable controls.
Create ONE original, expertly designed symbol, no typography, no presentation board.
Concept: a streamlined friendly blue whale in side profile, facing left, with a lifted forked tail on the right. Fuse the whale and an interactive UI into a SINGLE confident, coherent silhouette. Its broad rounded body has one clean rounded-rectangle negative-space cutout containing exactly one bold horizontal slider track and a circular slider thumb; this cutout should naturally read as an interactive card within the whale, with generous breathing room. Keep the whale instantly recognizable: arched back, clear tiny eye, elegant short belly fin, graceful tail. The negative-space UI slider is the sole detail that distinguishes this third-party GenUI extension from a plain whale logo.
Visual language: sophisticated flat vector-style brand mark, optically balanced curves, very high craft, geometric but warm. A single saturated DeepSeek-adjacent cobalt blue (#4D6BFE). Strong solid silhouette. NO gradient, NO shadows, NO outlines around the whale, NO 3D, NO glow, NO textures, NO sparkles, NO additional chart, NO cursor, NO letters or text. This must work as a small browser extension icon: bold forms, minimal details, no thin strokes.
Composition: square 1024x1024 image, symbol centered with 14 percent clear padding, roughly square bounding box, whale tail can sweep upward to balance the body. True transparent background. All cutouts transparent; no white background rectangle. Original reinterpretation evoking DeepSeek, not an exact copy of its official logo. Deliver only the logo artwork.
```

# 隐私说明（DeepSeek GenUI 0.1.1）

> 本项目为独立开发的第三方浏览器扩展，与 DeepSeek 官方无关。本文是扩展自首次发布起的正式隐私说明，覆盖 Edge Add-ons 商店开发者政策中「维护隐私政策」条款（1.5.2，最后更新 2026-07-24 版）。政策如更新，本文随复检同步更新并在 [CHANGELOG.md](../CHANGELOG.md) 记录。

## 一句话结论

本扩展**不收集、不存储、不传输任何聊天内容、用户输入或个人身份信息**；不发起任何网络请求；唯一使用的权限 `storage` 仅用于在本机保存一个功能开关。

## 数据明细

| 数据 | 收集/存储/传输 | 说明 |
| --- | --- | --- |
| 聊天文本、AI 回复、代码块内容 | 不存储、不上传 | 内容脚本仅在当前页面内存中读取 AI 回复 DOM，用于识别 `genui` 语言标记的代码块并渲染卡片；数据不离开页面、不写入任何存储 |
| 用户输入草稿 | 不存储、不上传 | 默认增强（追加提示词说明）与「继续讨论」（回填摘要）会读写当前输入框内容以完成其可见功能，均为页面内存操作，不持久化、不发送 |
| 功能开关 `genuiEnabled` | 仅本机存储 | `chrome.storage.local`（权限 `storage`），记录用户对增强开关的选择；卸载扩展即随之清除 |
| 网页浏览历史 | 无访问权限 | 未申请 `host_permissions` 与历史类 API |
| 遥测/分析/广告 SDK | 无 | 扩展不包含任何统计代码，不向任何第一方或第三方发送数据 |

## 权限说明

- `storage`：保存上述单本机布尔开关。这是扩展自身的功能必需权限，与浏览历史、网页内容读取权限无关。
- 内容脚本匹配范围严格限定为 `https://chat.deepseek.com/*`，在其他任何网站上不运行。
- 无后台 Service Worker，除页面本地行为外无执行面。

## 网络行为

扩展的运行时源码不包含任何网络 API（`fetch`/XHR/`sendBeacon`/WebSocket/`EventSource`），该性质由仓库内单测持续锁定（`tests/unit/extension-static.test.ts`）并由构建期校验（`scripts/check-dist.mjs`）保证：产物出现远程脚本、CDN 引用或动态执行即构建失败。数据传输因此不适用；无需 TLS 之类的传输保护声明。

## 第三方

- **数据共享**：不与任何第三方共享、上传任何数据（无网络 API，见上节）。
- **本地打包的第三方库**：产物 `content.js` 内打包了 `package.json` 声明的渲染依赖（React、react-dom），仅作为本地渲染库在本页面内运行，不与任何远端通信，不存在独立的数据收集行为；源码以可读形式公开于仓库。
- **外部服务**：扩展自身不调用任何第三方服务；卡片生成依赖 DeepSeek 网站自身的在线服务（登录与模型对话），该依赖是被增强站点的行为，不属于本扩展发起的网络请求。

## 用户控制

- 可随时通过页面上的「GenUI 已开启」开关关闭/恢复增强；
- 关闭开关时，扩展只移除仍完整的自动追加说明并保留用户原文；
- 卸载扩展会删除本机设置（`genuiEnabled` 开关的 `storage` 数据随扩展移除而清除）。**已打开页面中的注入效果（卡片、开关、根元素标记属性）不会在卸载瞬间自动消失，需刷新或关闭相应标签页后即可完全清除**，此后页面不再有任何注入痕迹。

## 验证方法（公开审计线索）

- 权限与来源：`dist/manifest.json` 只含 `storage` 与单一站点匹配；
- 网络不变量：源码与产品静态扫描结果见 [docs/phase8-verification.md](phase8-verification.md)；
- 构建可复现：见 [README.md](../README.md) 与 `release/` 发布包 SHA256。

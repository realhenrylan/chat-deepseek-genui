# 隐私说明（DeepSeek GenUI 0.1.1）

> 本项目为独立开发的第三方浏览器扩展，与 DeepSeek 官方无关。本文是扩展自首次发布起的正式隐私说明，覆盖 Edge Add-ons 商店开发者政策中「维护隐私政策」条款（1.5.2，最后更新 2026-07-24 版）。政策如更新，本文随复检同步更新并在 [CHANGELOG.md](../CHANGELOG.md) 记录。

## 一句话结论

本扩展**不收集、不上传任何聊天内容、用户输入或个人身份信息，也不发起独立的网络请求**；它只在 DeepSeek 页面内包装站点自身的 `fetch`，在你主动发送消息时把界面生成说明（以及你点选修复时的诊断详情）并入这条请求，并在页面读取历史消息或渲染用户气泡时，按完整协议正文与修复详情校验码剥离扩展追加的文本。权限 `storage` 仅用于在本机保存功能开关 `genuiEnabled` 与用户主动点击保存的卡片设置；卡片的交互状态只存在于当前页面内存，扩展不保存聊天正文，也不保存消息来源索引。扩展没有独立的服务器、统计或上传通道。

## 数据明细

| 数据 | 收集/存储/传输 | 说明 |
| --- | --- | --- |
| 聊天文本、AI 回复、代码块内容 | 不存储、不上传 | 内容脚本仅在当前页面内存中读取 AI 回复 DOM，用于识别 `genui` 语言标记的代码块并渲染卡片；数据不离开页面、不写入任何存储 |
| 用户输入草稿 | 不存储、不上传 | 扩展不再为了追加协议而读写你的输入框；「继续讨论」（回填摘要）与「生成修复请求」（写入一句简短触发文本）仍会按你的点击写入输入框，均为页面内存操作，不写入存储、不自动发送。发送时，页面内脚本会在你点下的那条站点聊天请求中并入生成说明或修复详情 |
| 功能开关 `genuiEnabled` | 仅本机存储 | `chrome.storage.local`（权限 `storage`），记录用户对增强开关的选择；卸载扩展即随之清除 |
| 卡片交互状态（参数、筛选、排序） | 仅页面内存 | 未点击保存时只存在于当前标签页的内容脚本内存，按卡片身份隔离，每会话最多 200 张卡片并淘汰最久未用项；刷新、关闭标签页或卸载扩展即丢失 |
| 主动保存的卡片设置 | 仅本机存储（用户触发） | 只有用户点击「保存当前界面」时才把该卡片的参数、筛选与排序写入 `chrome.storage.local`（键前缀 `genuiSavedState:`）；单条不超过 32 KB，最多 50 条，超出按保存时间淘汰；不含聊天文本、草稿或诊断；不跨设备同步，卸载扩展即清除 |
| 本地脱敏诊断 | 仅页面内存 | 只记录固定类别与代码的出现次数、首次/最近时间，以及适配器探针的计数与布尔值（含输入框候选数与是否唯一）；不含聊天文本、草稿、账号或会话 id；仅在用户主动打开「本地诊断」时预览，复制或下载均为显式操作，不写入存储、不上传 |
| 历史/气泡剥离 | 不存储 | 只在读取历史响应或扫描用户气泡时，于页面内存中比对「内置完整协议正文」或「带 FNV-1a 校验码的修复详情块」；匹配即移除尾部，不匹配保留原文。不保存消息 id、会话 id、正文摘要或任何剥离记录，刷新后仍按同一内容规则即时判断 |
| 网页浏览历史 | 无访问权限 | 未申请 `host_permissions` 与历史类 API |
| 遥测/分析/广告 SDK | 无 | 扩展不包含任何统计代码，不向任何第一方或第三方发送数据 |

### 本地诊断

「本地诊断」面板用于排查页面改版或延迟渲染造成的识别、等待、协议与挂载问题。它只在页面内存中保存固定词汇表内代码的计数与时间，以及站点适配器探针的计数/布尔值（例如回答容器数、候选代码块数、输入框候选数与是否唯一）；输入框缺失或存在多个候选时分别记录 `no-input` 与 `input-ambiguous`；**不记录聊天原文、完整草稿、账号 id、会话 id 或任何可还原对话的文本**。只有用户点击面板按钮时才生成预览；复制与「下载 JSON」都在本机由用户主动触发，不自动上传、不自动保存。诊断数据不写入 `chrome.storage.local`，关闭标签页即消失。详见 [站点适配接口与选择器维护](compatibility-investigation.md) 与 [状态保持](state-storage.md)。

## 权限说明

- `storage`：保存功能开关 `genuiEnabled` 与用户主动点击「保存当前界面」后的卡片设置。这是扩展自身的功能必需权限，与浏览历史、网页内容读取权限无关；扩展不读取或上传聊天记录，也不保存历史剥离所需的索引。
- 内容脚本匹配范围严格限定为 `https://chat.deepseek.com/*`，在其他任何网站上不运行。
- 无后台 Service Worker；全部逻辑只运行在 DeepSeek 页面内，没有独立进程或服务器。

## 网络行为

扩展不发起自己的网络请求，也不连接任何第三方服务。开启增强后，运行在页面 MAIN world 的 `interceptor.js` 会包装站点自身的 `window.fetch`：

- 在你发送聊天消息时，把界面生成说明（以及你点选修复时的完整诊断详情）并入这条由你触发的 DeepSeek 聊天请求体，再交还给站点发送；
- 在站点读取历史消息或渲染用户气泡时，只移除与内置完整协议正文逐字一致（忽略空白差异）的尾部，或带匹配 FNV-1a 校验码的修复详情块；不一致、被改动或只是引用首尾标记的内容保留原文。该判断不使用消息 id、会话 id 或任何本地记录；用户把完整协议或合法校验码的修复块原样粘贴在自己消息末尾属于已接受的极端情形；
- 只处理路径匹配 DeepSeek 聊天/历史接口、且请求体能安全解析的请求；其他请求原样放行，任何异常都会回退到原生 `fetch`，不阻断聊天。

因此聊天内容仍只发送到 DeepSeek（与不使用扩展时相同），扩展没有额外的数据出口；源码中不出现第三方域名、远程脚本或统计上报，构建期校验（`scripts/check-dist.mjs`）与静态单测（`tests/unit/extension-static.test.ts`）会拦截新增的远程引用。传输仍由站点自身完成，本扩展不新增 TLS 处理。

## 第三方

- **数据共享**：不与任何第三方共享、上传任何数据；仅在你发送消息时把协议文本并入由你触发的 DeepSeek 聊天请求（无独立网络出口，见上节）。
- **本地打包的第三方库**：产物 `content.js` 内打包了 `package.json` 声明的渲染依赖（React、react-dom），仅作为本地渲染库在本页面内运行，不与任何远端通信，不存在独立的数据收集行为；源码以可读形式公开于仓库。
- **外部服务**：扩展自身不调用任何第三方服务；聊天与历史请求都是 DeepSeek 网站自身的在线服务，扩展只在你触发的那条请求上增减扩展文本，不建立额外连接。

## 用户控制

- 可随时通过页面上的「GenUI 已开启」开关关闭/恢复增强；
- 关闭开关后，新发送的消息不再附带协议；已发出的历史消息仍会按内容规则在页面读取时被剥离（不依赖任何本机记录）；
- 关闭开关、切换会话或草稿被替换时，未发送的一次性修复暂存会立即失效；
- 卡片状态默认只在页面内自动保持；只有点击「保存当前界面」/「更新已保存的设置」才会写入本机，点击「清除保存」立即删除该卡片的记录；
- 未保存的刷新或关闭标签页会回到初始值；清除保存不改变当前界面上的值；
- 卸载扩展会删除本机设置（`chrome.storage.local` 中的开关与已保存的卡片设置）。**已打开页面中的注入效果（卡片、开关、根元素标记属性）不会在卸载瞬间自动消失，需刷新或关闭相应标签页后即可完全清除**，此后页面不再有任何注入痕迹。

## 验证方法（公开审计线索）

- 权限与来源：`dist/manifest.json` 只含 `storage` 与单一站点匹配；
- 状态范围：未保存的卡片状态只在 `src/runtime/card-state-store.ts` 的内存仓库中读写；`chrome.storage.local` 的读写只有 `src/content/settings.ts` 中的 `genuiEnabled` 与 `src/runtime/saved-card-state-store.ts` 中用户主动保存的卡片设置（前缀 `genuiSavedState:`）；历史/气泡剥离只在 `src/content/prompt.ts`、`src/content/interceptor.ts`、`src/content/site-adapter.ts` 的页面内存中按内容判断，不读写存储；字段与生命周期见 [状态保持与恢复](state-storage.md)；
- 网络行为：扩展不发起独立请求；`interceptor.js` 只包装站点 `fetch`，在匹配的聊天/历史接口上增减扩展文本，静态约束与产物检查见 `tests/unit/extension-static.test.ts` 与 `scripts/check-dist.mjs`；
- 构建可复现：见 [README.md](../README.md) 与 `release/` 发布包 SHA256。

# D06：提升图表与对比表格的可读性和一致性

状态：已发布，待开发。

GitHub：[#16](https://github.com/realhenrylan/chat-deepseek-genui/issues/16)。

## 问题与用户影响

图表使用固定多色调色板，部分轴标签较小；表格有筛选、排序、边框和横向滚动。它们的信息密度和视觉规则需要与卡片、数值和控件协调。

用户需要可靠地比较大小、变化和候选差异，并在需要时核对具体数据。

## 设计目标

通过清楚的配色、标签、对齐和结构，让图表与表格更适合比较和理解，并在不同主题和宽度下保持一致。

## 已确认的设计方向

- 一个主色加少量有意义的对比色；主色采用 DeepSeek 蓝，其他层次主要用黑白灰及蓝色深浅，并随主题切换。
- 数据图形突出，网格与标注克制，采样点按用途显示；详细数据默认收起，可以展开核对。
- 表格保持适中密度，窄栏仍保留比较表，名称便于定位，通过横向查看访问完整列。

颜色用于真实比较关系，不用额外色相做常规装饰。

## 验收方向

- 图表在亮/暗主题下都能区分数据、坐标与辅助网格。
- 单位、图例、数值和表格列名对应明确。
- 数值列易于比较，长中文和空结果不会破坏阅读顺序。
- 窄栏下能发现并使用查看完整数据的方式，重要内容不被静默丢失。
- 保留图表数据核对、表格筛选排序及本地联动行为。

## 范围与协作

依赖 D01–D03 的整体规范；与 D04 协调筛选及排序状态的视觉表现。

## 技术方案

- 保留 `charts.tsx` 的本地 SVG/HTML 实现，不引入图表库；默认系列配色改为来自 D01 的 DeepSeek 蓝、蓝色明度和中性灰变量，主题变化时同步。多系列以少量对比色、线型和文字图例共同区分，避免仅依赖颜色。
- 旧文档显式声明且符合现有协议的 `series.color` 保持其语义，不静默重写为另一种业务含义；新生成示例与提示词采用已确认的主配色。仅改变默认样式，不开放任意 CSS 或远程 paint server。
- 减弱辅助网格，确保坐标标签、单位和轴标题缩放后可读。沿用 smooth 连续曲线与离散点系列的区别：连续曲线减少点标记，离散样本保留必要点；不改采样值、插值公式、坐标映射和已有计算快照。
- 复用默认收起的“查看数据” details，同一次快照提供图形与数值。保留部分数据错误、饼图正值范围、空结果和负值提示。
- 表格保留语义 table、现有本地筛选/排序和可聚焦横向滚动区域。按列类型对齐数值；长中文合理换行，复杂长值可横向查看，不删除或自动隐藏列。
- 对首列为可判定文本标识的表格，使用局部 sticky 固定标识列，给出不透底的主题背景和轻边界；数值/无标识表格保留普通滚动，不根据“名称”等中文标题猜业务。超长标识限制占宽但保留完整可读内容，不能遮住全部数据列。
- 不增加新的表格/图表协议字段；调整现有渲染和组合示例。需要未来新增功能时继续按已有 issues 分工推进。

## 实现与验收

- [ ] 三种图表在亮暗主题中遵循黑白/DeepSeek 蓝主配色，数据、辅助网格、图例及焦点可区分。
- [ ] 多系列、单系列、显式旧颜色及连续/离散系列均有对照；不能改变数据含义或计算结果。
- [ ] 展开数据表能核对图形数值，样本显示与插值区分清楚；错误、全零、正负混合及空数据有确定反馈。
- [ ] 在 360px/560px/720px 卡片宽度中保留完整列；横向滚动时标识可定位、固定列不会遮住数据，键盘能访问全部信息。
- [ ] 筛选、排序、条件行及重置继续有效，纯主题/宽度变化不会清空视图状态。
- [ ] 覆盖长中文、长单位、纯数值表、缺失值、200% 缩放，以及图表与表格的同快照一致性。

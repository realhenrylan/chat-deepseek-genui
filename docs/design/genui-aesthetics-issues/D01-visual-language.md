# D01：统一 GenUI 的基础视觉语言与明暗主题

状态：已发布，待开发。

GitHub：[#11](https://github.com/realhenrylan/chat-deepseek-genui/issues/11)。

## 问题与用户影响

当前灰色透明背景、描边、间距、圆角等数值分别定义在不同组件中。现有明暗主题能工作，但缺少一套明确的视觉层次，容易让控件、表格和提示像各自独立设计的部件。

用户需要快速理解哪个区域是主要内容、哪个元素可以操作，以及哪些信息是辅助说明。

## 设计目标

形成适合嵌入 DeepSeek 对话的视觉语言；卡片、控件、图表和表格在明暗主题下表现一致，主题变化后仍保持清楚的主次和可读性。

## 已确认的设计方向

- 融入 DeepSeek 对话：轻边界、少装饰、与宿主协调。
- 信息密度适中：核心内容清楚，细节按需展开。
- 适度突出一至两个主要结果，其余数值较安静。
- 主要配色采用随主题切换的默认白、默认黑，以及 DeepSeek 蓝；中性灰用于辅助层级，必要的错误/警告色仅表达状态。

上述方向已确认，具体组件按 D02–D06 的已确认方案统一落地。

## 验收方向

- 同一类表面、边界、文字和状态在不同组件中表达一致。
- 亮/暗主题均可区分主要内容、辅助信息和可操作元素。
- 样例界面的风格统一，颜色不会干扰对数值和文字的阅读。

## 范围与协作

本 issue 定义共同视觉规范，D02–D06 将其应用到具体场景。

## 技术方案

- 保留 React、原生 CSS 和现有 Shadow DOM 挂载方式；本系列不引入 Tailwind 或外部组件库。
- 在 `src/render/card.css` 的卡片根节点定义 `--genui-*` 语义变量，覆盖表面、主/次文字、边界、主色、状态、间距、圆角及字号。由现有 `data-site-theme` 切换亮暗值，复用 `theme.ts` 的检测和生命周期清理。
- 默认黑白跟随宿主主题，缺少可用宿主值时使用白/黑回退；主蓝沿用仓库品牌资产的 `#4D6BFE`。浅深层次使用中性明度，常规区域不引入额外色相或彩色背景。
- 统一替换分散的 `#3988ff`、灰色透明度及重复尺寸；间距基于 4/8/12/16/24px，圆角采用少量固定等级。具体值需通过三类样例的亮暗对照校正。
- 正文继承宿主字体栈，保留中文系统回退；不新增远程字体或资源。普通文字对比度至少 4.5:1，达到大字条件的文字至少 3:1；按钮文字、焦点与数据图形分别检查，不能假定品牌蓝适合所有文字背景。

## 实现与验收

- [ ] 亮暗主题切换仅更新视觉，不重新挂载卡片或丢失当前输入。
- [ ] 预算、选购、函数示例共享相同表面、文字与控件规则；辅助文字可读。
- [ ] 同数据截图覆盖 360px、560px、720px 卡片宽度及 200% 页面缩放，记录实际对比度检查结果。
- [ ] 执行主题/卡片相关回归及生产包检查，确认 CSS 隔离和原始内容回退保持。

- 与 #2 相交于主题/布局变化时的状态保持：本 issue 不实施状态持久化，也不宣称解决页面重新挂载丢值。

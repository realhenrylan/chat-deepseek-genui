# 阶段 9 最终版本模型样本

本目录保存 issue #4 复核后，用**当前 v2.5 提示词与 v5 协议**重新采样的真实模型输出，用于复核最终版本的首轮可用率与计算正确性。

- `v5-final-budget.md`：月度预算任务（收入 12000，支出 4500/2600/600/900，餐饮与其他可调）。
- `v5-final-preference.md`：四款笔记本偏好比较（价格/重量/续航，权重 40/30/30，预算与重量筛选，D 缺续航）。

采样方式：DeepSeek 子代理在只读取 v2.5 系统提示与任务描述的条件下生成，回答只含一个 `genui` 代码块；未读取仓库示例。原始文件按生成结果原样保存，未修改。两份样本由 `tests/unit/model-samples.test.ts` 在当前协议下解析、求值并断言关键结果。

样本量只有 2，且来自同一模型家族、非生产 API；它们补足“最终版本可复跑”的证据，不构成统计结论。早期 9 例混合版本采样见 [`../phase9-model-comparison.md`](../phase9-model-comparison.md)。

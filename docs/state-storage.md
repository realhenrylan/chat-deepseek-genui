# 卡片状态保持与恢复

本文说明交互卡片的状态在页面内如何保持，以及刷新、重新挂载、文档改写和切换会话时的重置规则。实现对应 issue #2，相关代码在 `src/runtime/card-state.ts`、`src/runtime/card-state-store.ts`、`src/content/identity.ts`、`src/content/enhance.ts` 与 `src/render/Card.tsx`。

2026-11-04 起移除了手动「保存方案」、`genui-plan` 方案文件与「方案工作台」；本文件只描述仍在使用的页面内状态保持。

## 一句话结论

- 页面内：调整过的参数、表格筛选与排序自动保存在当前标签页内存中，生成新回答、同一文档的节点替换或重新挂载不会回到初始值。
- 刷新后：不恢复，回到文档初始值；卡片状态不写入 `chrome.storage.local`，也不跨标签页、跨会话同步。
- 跨会话/跨消息：不会串用；身份有歧义时退化为元素级一次性键，宁可重新挂载后回到初始值。
- 状态保持不会让模型知道你当前的选择；需要把条件带回对话时，使用「继续讨论」生成的摘要并自行发送。

## 状态层

| 层 | 触发 | 存放位置 | 生命周期 |
| --- | --- | --- | --- |
| 页面内状态 | 调整参数、筛选、排序时自动写入 | 内容脚本内存（每个会话最多 200 张卡片，按最近使用淘汰，`MAX_IN_MEMORY_CARD_STATES = 200`） | 当前标签页；刷新或关闭页面即丢失 |

没有第二层持久化。卡片底部不再有保存/清除入口，扩展也不会主动替用户保存交互状态。

## 身份：怎么判断「还是同一张卡片」

状态键由五段组成，不按标题或 DOM 顺序匹配：

```
card|<状态结构版本>|<账号作用域>|<会话路由>|<消息键>|<同文档重复序号>|<原始文档哈希>
```

- **账号作用域**：读取站点提供的 `data-user-id` / `data-account-id` / `meta[name="user-id"]` 等稳定标记，哈希后使用；缺失时统一为 `acct-unknown`。原始账号 id 不进入键。
- **会话**：只接受 `/a/chat/s/<会话 id>` 形式的路由，去掉末尾斜杠；其他路由一律视为 `unknown-session`。
- **消息**：优先取最近的 `data-virtual-list-item-key`，其次 `data-message-id`；两者都没有时退化为消息文本指纹（不可靠）。
- **重复序号**：同一消息内出现次序；一旦出现完全相同的文档，该序号不再参与区分。
- **文档哈希**：原始 genui JSON 文本的哈希。原文一旦变化就得到新键，旧状态不会被套用到新文档。

身份有歧义时（只有文本指纹、同一消息键被多个消息共用、或同一消息内出现完全相同的文档），这些卡片不再共享状态键，改为按 DOM 元素分配一次性键（`amb|<元素令牌>|<文档哈希>`）。同一元素跨扫描保持稳定，但节点替换后即失效；宁可丢失状态，也不让相邻卡片串值。

## 兼容与重置

| 变化 | 行为 |
| --- | --- |
| 同一文档的节点替换、虚拟列表回收后重新挂载 | 身份无歧义时恢复参数、表格筛选与排序；身份有歧义时为元素级键，重新挂载后回到初始值 |
| 原始代码块被改写（哪怕标题相同） | 文档哈希变化 → 新身份；旧内存状态删除，按新文档初始值挂载 |
| 状态结构版本升级 | 旧状态不应用；按新文档初始值挂载 |
| 状态变量类型、取值域、步长、选项变化 | 旧值按当前文档重新校验，越界或失效项回落到该字段初始值，其余合法值保留 |
| 表格列变化、排序列不再存在 | 丢弃该排序，筛选文本保留并重新过滤 |
| 切换账号、会话、消息或相同标题 | 键不同，互不串用；账号标记缺失时以会话路由与消息键为主要隔离边界 |
| 刷新或关闭标签页 | 内存清空，回到初始值；没有恢复入口 |

## 操作与反馈

- **重置当前界面**：恢复初始参数并清空筛选，回到初始排序；只影响当前卡片。
- 状态保持是自动的，没有保存/清除按钮，也没有容量清理或失败提示。
- 卡片不读取、不写入 `chrome.storage.local`；开关状态仍由唯一的 `genuiEnabled` 键保存。

## 边界与已知限制

- 页面内状态只存在于当前标签页，刷新、关闭标签页或卸载扩展后消失；跨设备不同步。
- 同一消息内出现完全相同的文档，或两条消息共用同一消息键时，身份转为元素级：宁可重新挂载后回到初始值，也不共享状态。
- 状态保持只影响界面，不改变对话上下文；模型不会自动知道当前选择。
- 依赖 DeepSeek 当前页面结构；站点改版可能影响消息标记、会话路由或挂载，进而影响状态恢复。

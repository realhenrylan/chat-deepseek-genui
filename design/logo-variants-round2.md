## 07 — 状态切换 / Transition

1. **架构**：抽象动作符号 + 横向名称组合，另提供纵向组合与独立符号。
2. **字体**：Manrope 650；DeepSeek 与 GenUI 同基线，字距 -0.012em，词间距 0.28em。完整名称保持 DeepSeek GenUI。
3. **符号**：两个实心状态块构成近方形外轮廓，阶梯形留白将两个状态衔接起来。只表达“操作带来变化”这一件事。
4. **色彩**：主蓝 #4D6BFE；名称 #152137；单黑 #000000；反白 #FFFFFF，暗底 #111A2B。
5. **应用**：近方形轮廓适合工具栏和头像；16/28px 使用扩大占比的微型版本，32px 起用标准图形；页头用横向组合。
6. **传达**：参数、选择或输入发生改变后，界面进入新的状态；与 GenUI 的交互反馈能力关联。
7. **取舍**：不直接描画界面控件。可能先被读成阶梯、折线或抽象字母，需要与完整名称共同建立识别。
8. **应用示意**：[页头、实际尺寸工具栏、暗底、名片、刺绣规划](logo-variants/07-transition/applications.png)。
9. **文件**：[主标志 SVG](logo-variants/07-transition/primary-blue.svg) · [符号 SVG](logo-variants/07-transition/symbol-blue.svg) · [纵向组合](logo-variants/07-transition/stacked-blue.svg)。

**构造与制作建议**

- 104u 画布，可见外边界约 16–88u；外角以 12–20u 的圆滑过渡构成，两个实心形状独立填充。
- 两端水平留白为 16u，斜向留白的垂直于边缘净宽约 14.1u；图形不依赖描边。
- 16/28px 微型版将 8–96u 区域映射回完整画布，保留同样的轮廓关系。
- 正常布局安全间距 ≥0.25S，S 为可见图形高度。建议独立符号 ≥16px；完整横向组合 ≥180px；纵向组合 ≥160px。
- 进入动效可在 180–220ms 内让两部分从 4u 位移归位，留白随之形成；退出整体淡出；减少动态效果时静态显示。
- 38.1mm 刺绣章中建议符号可见高度约 25mm；上述最窄留白约为 4.9mm，便于保持层次，仍需实物打样。
- 压印建议符号高度 ≥12mm，最小线宽、间距按 ≥0.35mm 规划后根据材质补偿。

**本轮推荐：首选。** 与前六案的轮廓差异大，缩小后仍保留阶梯留白这一记忆点。

## 08 — 界面构成 / Workspace

1. **架构**：模块化图形 + 横向名称组合，另有纵向组合。
2. **字体**：Source Sans 3 600；字距 -0.012em，词间距 0.28em；较亲和的字形配合稳定的界面模块。
3. **符号**：一个纵向区域，配合右侧上下两个不同高度的模块。三个块面归纳界面布局，不画窗口边框与控件细节。
4. **色彩**：主蓝 #4D6BFE；名称 #152137；单黑 #000000；反白 #FFFFFF / 暗底 #111A2B。
5. **应用**：工具栏、扩展介绍和组件相关展示都容易理解；原生近方形，16/28px 用微型版，32px 起用标准版。
6. **传达**：针对问题组合不同的展示区域和操作工具；让内容具有可用的界面结构。
7. **取舍**：含义直接，但接近通用布局或仪表盘图标；更依赖完整名称、固定比例和一致应用积累辨识度。
8. **应用示意**：[五种上下文](logo-variants/08-workspace/applications.png)。
9. **文件**：[主标志 SVG](logo-variants/08-workspace/primary-blue.svg) · [符号 SVG](logo-variants/08-workspace/symbol-blue.svg) · [纵向组合](logo-variants/08-workspace/stacked-blue.svg)。

**构造与制作建议**

- 104u 画布，三个实心圆角矩形：24 × 72u、36 × 24u、36 × 36u；圆角半径 7u。
- 水平与垂直沟槽均为 12u；不添加细线、阴影或色彩分层。
- 微型版与 07 一样扩大占比；图形结构保持一致。
- 安全间距 ≥0.25S。建议独立符号 ≥16px；横向组合 ≥180px；纵向组合 ≥160px。
- 动效可让三个模块在 180ms 内依次出现，间隔约 35ms；保持最终排列，避免持续跳动。
- 刺绣使用三个独立色块；25mm 可见高度时模块间距约 4.2mm。压印建议可见高度 ≥12mm；材料打样重点看圆角填充和间距。
- 字体与图形均提供单黑、反白和轮廓 SVG。

**定位：功能表达最直观的备选。**

## 09 — UI 连字 / Joined UI

1. **架构**：从 UI 衍生的定制小写 ui 连字 + 完整名称组合。它是独立字母标，主名称仍按 DeepSeek GenUI 的大小写呈现。
2. **字体**：主字标 Manrope 650，字距 -0.012em；连字为本轮绘制的实心路径，不依赖字体字符。完整名称与符号的粗细存在刻意的层级关系。
3. **符号**：u 的下部与 i 的竖画通过同一条基线连接；i 的方形点保留模块感。重点是字母与界面的关联，不增加外框。
4. **色彩**：主蓝 #4D6BFE；名称 #152137；单黑 #000000；反白 #FFFFFF / 暗底 #111A2B。
5. **应用**：大图形与工具栏使用同一连字结构；16/28px 扩大占比，32px 起标准版。无需额外切换成其他字母。
6. **传达**：界面能力、可操作性，以及短而清楚的字母记忆点。
7. **取舍**：ui 是类别词，含义清楚但词本身不具独占性；i 的点和底部连接需要持续保持固定比例。
8. **应用示意**：[五种上下文](logo-variants/09-joined-ui/applications.png)。
9. **文件**：[主标志 SVG](logo-variants/09-joined-ui/primary-blue.svg) · [连字 SVG](logo-variants/09-joined-ui/symbol-blue.svg) · [纵向组合](logo-variants/09-joined-ui/stacked-blue.svg)。

**构造与制作建议**

- 104u 画布，可见边界为 16–88u。u 的侧壁与 i 的竖画以 16u 厚度为主，底部 16u 横桥使它们连成一个结构。
- i 的点为 16 × 14u，圆角半径 3u；点与竖画间距 10u，u 与 i 的上段间距 8u。
- 16/28px 微型版扩大占比后仍保持这两个分隔；点、竖画和 u 内部空间是小尺寸检查的重点。
- 安全间距 ≥0.25S。建议独立符号 ≥16px；横向组合 ≥180px；纵向组合 ≥160px。
- 动效建议先整体显示 u 与 i 的连体部分，再于 60ms 后显示方形点；总时长约 180ms。退出整体淡出。
- 刺绣章内建议图形高 ≥25mm；最窄 8u 间距约为 2.8mm。压印建议 ≥12mm，保持点、竖画分开，按 ≥0.35mm 最小间距进行材料打样。
- 符号均为填充路径与矩形，不使用图像描摹、渐变或描边。

**定位：新增三案中，名称字母关联最清晰的方向。**

## 版本与检查

| 上下文 | 07 状态切换 | 08 界面构成 | 09 UI 连字 |
|---|---|---|---|
| 16/28px | 扩大占比；保留阶梯留白 | 扩大占比；三块分开 | 扩大占比；保留点与竖画间隔 |
| 32px 及以上 | 标准版 | 标准版 | 标准连字 |
| 单色 / 反白 | 单黑与白色 SVG / PNG | 单黑与白色 SVG / PNG | 单黑与白色 SVG / PNG |
| 方形展示 | 单符号或纵向组合 | 单符号或纵向组合 | 单连字或纵向组合 |
| 页头 | 符号 + 完整名称 | 符号 + 完整名称 | 连字 + 完整名称 |
| 实物制作 | 构造规划，待打样 | 构造规划，待打样 | 构造规划，待打样 |

数字检查包括 SVG XML、字体转轮廓、透明 PNG 尺寸与边缘留白、评审页本地资源链接，以及实际像素与放大预览。应用图是示意；陌生用户记忆、真实工具栏和实物输出需在所选方向上继续验证。

类别近似性初查发现 GU 连字已有多种现成案例，因此本轮字母方向改用与界面相关的 ui，并独立绘制连接关系。检索参考：[GU 标志集合](https://designbundles.net/xcoolee/2365174-gu-logo-design)、[现有 GU 标志展示](https://www.lutzgruppe.de/beschlaege.html)。这一步用于设计取舍，不构成完整近似检索。

文件目录沿用上一轮，每案提供主标志、纵向组合、标准与微型符号的蓝/黑/白 SVG；16/28/32/48/128px 透明图标、大图 PNG 和五种应用示意。字体许可仍随 fonts/ 附带；符号为新增原生 SVG 构造。

**新增三案优先推荐 07。** 若更在意字母的含义，比较 09；若希望用户一眼联想到界面布局，比较 08。
